A graduate of **Information Systems** and the **Fullstack JavaScript Bootcamp at Hacktiv8**. I focus on developing **web** and **mobile applications** using **React**, **Next.js**, **Flutter**, **Express.js**, **MongoDB**, **PostgreSQL**, and other modern technologies.  
I'm passionate about **AI**, always eager to learn new things, and enjoy building impactful digital solutions.
